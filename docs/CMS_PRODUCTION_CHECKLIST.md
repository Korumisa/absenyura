# Checklist konten CMS produksi

Isi lewat panel **Konten Website** (bukan lewat kode).

## Profil organisasi

- [ ] Nama organisasi & kampus
- [ ] Hero subtitle, logo, warna utama
- [ ] Tentang (paragraf)
- [ ] Visi & misi
- [ ] Kontak: email, telepon, alamat
- [ ] Tautan Instagram, TikTok, YouTube

## Rekrutmen

- [ ] Minimal 1 open recruitment **published**
- [ ] Periode pendaftaran (tanggal mulai & selesai)
- [ ] Link form `https://...`
- [ ] Poster (opsional)

## Struktur & konten

- [ ] Struktur organisasi (grup + anggota)
- [ ] Minimal 1 program kerja published
- [ ] Berita/kegiatan terbaru

Setelah publish, tunggu hingga 1 menit (cache API) atau hard-refresh beranda.
